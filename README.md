# Daily Expense Tracker

A simple website to keep track of daily expenses and manage spending in one place. This project was made as part of my Web Development course using HTML, CSS and JavaScript.

## About the Project

The Daily Expense Tracker helps users record their expenses and keep an eye on where their money goes. It has a simple layout that makes it easy to add expenses, view previous entries and check monthly spending.

## Features

- **Dashboard:** Shows total expenses, number of entries and recent expenses.
- **Add Expense:** Add an expense with its name, amount, category, date, payment method and description.
- **Expense History:** View, search, filter, sort, edit and delete expense entries.
- **Monthly Reports:** Check monthly spending and see how expenses are divided across categories.
- **Indian Currency:** Expenses are displayed in Indian Rupees (₹).
- **Temporary Storage:** Expense data is stored in the browser for the current session.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Use the dashboard to add expenses and explore the other pages.

No additional installation is required.

## Project Files

- `index.html` – Main dashboard
- `add-expense.html` – Form to add new expenses
- `history.html` – List of recorded expenses
- `reports.html` – Monthly expense reports
- `style.css` – Styling and layout
- `script.js` – Functionality and expense management

## Note

This is a basic front-end project created for learning web development. The expenses are stored using browser `sessionStorage`, so they are temporary and are cleared when the browser tab's session ends. The data is not stored in a permanent database.
